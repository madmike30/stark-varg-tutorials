# Remove and Install Front Number Plate - Stark VARG MX 1.2 / EX

Source video: `Remove and Install Front Number Plate - Stark VARG MX 1.2` by Stark Future Official

Applicable models: `MX 1.2 / EX`

## Scope

This guide follows the same step-by-step workshop structure as the MX tutorials, but it is derived as a visual sequence from the official Stark Future ASMR video. Because the EX video does not provide usable captions or narration, the procedure is documented through curated screenshots and concise action guidance.

## Preparation

- Place the bike on a stable stand or work area before starting the procedure.
- Prepare the correct tools for the fasteners, clips, brackets, and components shown in the video.
- Keep removed hardware organized in sequence so reassembly follows the same order as the video.
- Have a torque wrench ready for any tightening steps that specify a torque value.

## Removal Procedure

### 1. Prepare access to the Front Number Plate

Remove or move aside the surrounding part, cover, or hardware needed to reach the Front Number Plate.

Keep the removed fasteners organized in sequence so reassembly matches the video.

### 2. Remove the visible retaining hardware for the Front Number Plate

Remove the bolts, screws, nuts, or clips that directly secure the Front Number Plate.

Support the component as the last fastener is removed.

![Step 2 - remove the visible retaining hardware for the front number plate](assets/screenshots/step_02_remove-the-visible-retaining-hardware-for-the-front-number-p.jpg)

### 3. Release any bracket, clip, or coupling attached to the Front Number Plate

Free any bracket, clip, spacer, linkage, or connector that still ties the Front Number Plate to the bike.

Note the orientation of these supporting pieces before setting them aside.

![Step 3 - release any bracket, clip, or coupling attached to the front number plate](assets/screenshots/step_03_release-any-bracket-clip-or-coupling-attached-to-the-front-n.jpg)

### 4. Remove the Front Number Plate from the bike

Lift, slide, or guide the Front Number Plate out of its mounting position once the retaining hardware is removed.

Inspect the removed part and the mounting points before reassembly.

## Installation Procedure

### 5. Position the Front Number Plate for installation

Return the Front Number Plate to its mounting position and align the holes, tabs, or locating surfaces.

Hold the component in place until the first retaining hardware is started.

![Step 5 - position the front number plate for installation](assets/screenshots/step_05_position-the-front-number-plate-for-installation.jpg)

### 6. Reconnect or refit the support pieces for the Front Number Plate

Reinstall any bracket, clip, spacer, linkage, or coupling associated with the Front Number Plate.

Make sure each supporting piece is seated correctly before final tightening.

![Step 6 - reconnect or refit the support pieces for the front number plate](assets/screenshots/step_06_reconnect-or-refit-the-support-pieces-for-the-front-number-p.jpg)

### 7. Install the retaining hardware for the Front Number Plate

Install the main retaining hardware for the Front Number Plate by hand first, then tighten it evenly.

Check that the component remains aligned while the hardware is brought fully home.

![Step 7 - install the retaining hardware for the front number plate](assets/screenshots/step_07_install-the-retaining-hardware-for-the-front-number-plate.jpg)

### 8. Verify the completed installation of the Front Number Plate

Inspect the final position of the Front Number Plate and confirm that all hardware, clips, and surrounding parts are back in place.

Check the component for correct fit and movement before returning the bike to service.

![Step 8 - verify the completed installation of the front number plate](assets/screenshots/step_08_verify-the-completed-installation-of-the-front-number-plate.jpg)

## Critical Checks Before Riding

- Confirm the serviced component is fully seated and all fasteners are tightened in the correct order.
- Recheck all torque-critical hardware before riding.
- Make sure all routed cables, clips, brackets, and surrounding parts are returned to their original positions.
- Inspect the bike visually for any missing hardware before returning it to service.
